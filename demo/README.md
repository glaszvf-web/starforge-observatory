# 演示数据说明

本目录全部为合成数据，用于展示 Agent Ops 的数据结构、布局和交互。**不含任何真实记忆或个人信息。**

| 文件 | 内容 |
|---|---|
| `layers/l0.json` | 原文层元信息与映射统计 |
| `layers/l1.json` | 48 条原子记忆 |
| `layers/l2.json` | 8 个场景 |
| `layers/l3.json` | 画像与分类汇总 |
| `cortex/graph.json` | 8 个分区、16 条连接、48 个图谱节点 |
| `cortex/meta.json` | 指纹、计数、层级统计 |

演示主题围绕“项目节奏、工具链、视觉规范、交互设计、验证方法、数据接口、工作流规则、复盘记录”，条目文本是通用工程经验，不指向任何真实个人或项目。

本目录是静态样例，直接使用即可。

## 替换为真实数据

把你的数据目录按同样结构组织，然后：

```bash
DSH_MEMORY_DIR=/path/to/Memory node bin/server.mjs --port 8902
```

或在项目根目录设置环境变量 `DSH_MEMORY_DIR`。服务不会写入数据目录，只读。
